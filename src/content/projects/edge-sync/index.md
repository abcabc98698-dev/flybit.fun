## Overview

**EdgeSync** is a lightweight, local-first synchronization protocol engineered to keep Markdown vaults, metadata, and asset bundles seamlessly synchronized across edge devices without relying on centralized, proprietary sync services.

### Key Capabilities
- **Local-First Architecture**: Your local files remain the authoritative single source of truth.
- **Zero Lock-In**: Operates transparently with standard Git repositories and distributed object storage.
- **Conflict Resolution**: Deterministic state merges optimized for Markdown documents and frontmatter schemas.
- **End-to-End Encryption**: Cryptographically sealed payloads ensuring maximum privacy and digital sovereignty.
