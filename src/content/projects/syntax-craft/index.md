## Overview

**SyntaxCraft** is an opinionated typography and design token framework engineered specifically for technical documentation, source code display, and long-form engineering essays.

### Key Capabilities
- **Radical Readability**: Scientifically calibrated measure (line length), typographic scale, and optical line heights.
- **Zero Layout Shift**: Strict asset dimensioning and font fallback metrics preventing cumulative layout shifts (CLS).
- **Four Cohesive Themes**: Seamlessly transitions between Clean White, Warm Paper, Slate Navy, and Midnight OLED palettes.
- **WCAG 2.1 AAA Contrast**: Fully audited color combinations that respect high-contrast and reduced-motion user preferences.
