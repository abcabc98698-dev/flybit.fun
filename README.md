**Flybit** is a high-performance, typography-first static knowledge hub and engineering publication architecture built on [Astro 7](https://astro.build). Engineered for software architects, systems engineers, and technical researchers, Flybit delivers pure static HTML with zero client-side bloat, instant edge CDN delivery, and full digital sovereignty.

---

## ✨ Key Features

* **⚡ Pure Static Site Generation (SSG):** 100% pre-rendered at compile time for instantaneous page loads and zero server maintenance.
* **✍️ Typography-First Architecture:** Calibrated vertical rhythm, optimal measure (line length), and elegant typographic scale designed for technical reading.
* **🎨 4 Handcrafted Reading Palettes:**
  * ☀️ **Clean White:** Crisp, modern editorial light mode.
  * 📜 **Warm Paper (Cream):** Eye-friendly soft palette for extended reading sessions.
  * ⚓ **Slate Navy:** Deep, focused dark mode for technical coding.
  * 🌌 **Midnight OLED:** Pure OLED black with high contrast.
* **📝 Obsidian & Local-First Native:** Write comfortably in desktop Obsidian with local page bundles and immediate preview.
* **🔍 Instant Search & Accessible Narration:** Keyboard-driven search (`Ctrl + K`) and built-in text-to-speech Web Speech API audio player.
* **📊 SEO & Agent Ready:** Full Schema.org JSON-LD structured data, OpenGraph cards, sitemap index, and `llms.txt` endpoints for AI agents.

## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview static build
npm run preview
```
